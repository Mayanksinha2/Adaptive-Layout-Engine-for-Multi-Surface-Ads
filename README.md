# Adapti — Adaptive Layout Engine for Multi-Surface Ads

A frontend R&D assignment demonstrating reusable React + TypeScript components, responsive layout rules, controlled form state, image upload, format switching and client-side PNG export.

## Features
- Square 1:1, Portrait 4:5, Story 9:16 and Wide 3:1 surfaces
- Adaptive typography, copy placement and product image placement
- Editable headline, description, offer, CTA and colors
- Local image upload
- PNG export using `html-to-image`
- Responsive UI for desktop and mobile
